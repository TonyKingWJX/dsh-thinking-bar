# 思考等级 UI · 预览

双击 `index.html` 即可（Chrome / Edge）。纯静态、`file://` 可用，React 与 DSH 主题 token 已内置在 `vendor/`，不需要联网。**默认浅色主题**，`?dark=1` 切深色。

## 两种形态

| 形态 | 行为 |
|---|---|
| **官方**（插件默认） | 插件不注册任何座位，模型选择器与推理等级完全交还 DSH；右侧用近似复刻展示官方基线。 |
| **Codex**（手动切换） | 只替换 `conversation.input.model` 座位：关闭态与官方同几何（28px、13px、同一组省略与长名变量），仅档位文字上色；展开是 Codex 卡片。 |

## 六种滑杆视觉

同一形态内可选，不新增形态：

- **Codex**：蓝紫渐变 + 粒子，档位越高粒子越多、越快；
- **能量充能**：格点充能场，越靠近当前档越亮，Max 持续燃烧；
- **曲率跃迁**：已填充段是深空 + 星流拖尾，档位越高越快越长；
- **量子纠缠**：已填充段是深空网格 + 双波干涉 + 脉冲环；
- **鲸鱼娘**：浅海蓝弹层，120px 大表情浮在文字上方（不是圆形滑块，也不撑大卡片），7 档 7 张原创鲸鱼娘表情、每档不同小动作；弹层用浅海+鲸鱼娘虚影背景；保留 Off…Max 英文档位；
- **梁圣**：深色金系弹层，整帧梁文峰头像做弹层背景（不再是小方块头像），背景随档位换成对应帧；档位改为 **梁子 / 小梁 / 梁叔 / 梁哥 / 梁总 / 梁神 / 梁圣**。所有 effort 卡片固定 **356×130px**，角色可溢出到卡片上方。

曲率/量子的未填充段保持主题轨道底色（浅灰/深灰）；深空只在滑块左侧的已填充段。

角色主题使用各自固定配色和轨道，**档位配色面板会暂时禁用**；切回 Codex/能量/曲率/量子后恢复。

## Codex 卡片

从上到下：

1. 左上闪电开关、中间当前档位（英文、按档位上色）、右上重置；
2. 模型名 + `›`，点击进入官方样式的模型面板；鲸鱼娘/梁系与 Codex 使用同一面板尺寸，主题背景会随面板高度扩展；
3. 30px 胶囊滑杆：填充区带粒子，档位越高粒子越多越快；34px 白色滑块（比轨道略大，平面 1px 边框）；
4. 底部英文档位：Off / Minimal / Low / Medium / High / Xhigh / Max。

没有“推理强度”小标题、没有 `5/7` 计数、没有底部键盘提示行。主会话卡片在档位减少（5 档、3 档）时，渐变、标签位置、粒子数量会按实际档位重排；右侧设置预览为固定样式，始终展示 7 档。

## 角色主题

### 鲸鱼娘

- 弹层是浅海蓝卡，背景是我们用鲸鱼娘素材合成的**浅海 + 全身虚影**（没有用 Gemini 生成的背景图）；
- 卡片固定 356×130px；滑块不是圆形，而是 **120px 大表情**（完整头部+肩部）**放在 30px 轨道上并上移**，上下溢出部分浮在文字上方，左右允许超出卡片；7 档分别对应 7 张原创表情；
- 档位标签按卡片全宽排布（不再被大滑块挤在中间），7 档间距均匀；
- 每档有不同的小动作（犯困呼吸、干饭咀嚼、紧张发抖、思考歪头、开心弹跳、生气摇晃、神化呼吸），并遵守 `prefers-reduced-motion`；
- 轨道是浅海泡泡带 + 浅蓝填充，标签/等级名用深蓝系；角色周围有蓝色脉冲光晕，轨道气泡持续上浮、填充亮度缓慢呼吸。

### 梁圣

- 滑块就是**他的整张图片等比缩小**：120×120 完整画面（含上半身和原图背景），1px 金色描边，浮在轨道上方，随档位切换对应帧，不做抠图；
- 弹层背景用同一帧的**模糊/压暗版** `cover`，既有他的背景，又不会和滑块上的脸重复抢视觉；
- 7 档：梁子 → 小梁 → 梁叔 → 梁哥 → 梁总 → 梁神 → 梁圣；
- 轨道为深色金纹，标签与等级名使用金色系；角色有金色脉冲光晕和轻微浮动，轨道有扫光，填充有金色呼吸。
- 选中鲸鱼娘/梁系时，右侧“档位配色”整块隐藏（主题固定配色）；设置里的选中按钮用蓝色强调色。

## 设置页预览

右侧面板顶部（形态上方）是一块**只保留弹层本身**的样式预览，没有触发器、输入框或其他对话框，也**不与会话的模型/等级联动**：

- 固定模型 **DeepSeek-V4.1-Flash**，模型名只是静态标签，不能换模型；
- Codex/角色主题预览：只能调推理强度（拖动、闪电、重置、点档位），只能切视觉/深浅色；
- 官方预览：根菜单里模型行固定，只能点“推理等级”进入档位列表；
- 预览里的选择不会读/写主会话的模型或等级；主会话窗口的座位默认收起，可单独测试。

## 交互

- **分体点击**：关闭态点模型名 → 模型列表，点推理等级/箭头 → 档位滑杆；官方形态仍走官方菜单。
- **角色可直接抓**：鲸鱼娘/梁系的 120px 素材本身就是可拖动把手，按住素材左右拖即可调档；素材超出卡片的上下左右区域也能抓。
- 拖动时滑块连续跟手，越过阈值才切档位；卡片顶部等级名和触发器等级实时跟着变。
- 上下拖动不会回到 Off；pointercancel 不提交。
- **闪电 / 重置**：滑条与滑块用 220ms ease-out 缓动到目标档位。
- **松手立即提交一次并保持展开**；键盘微调仍用 200ms 防抖。
- 点击档位文字：主窗口应用并关闭；设置预览里应用但保持展示。
- 主窗口 `Esc` 或点卡片外关闭；设置预览固定展示。

## 直接定位到某个状态

```
?mode=official            官方形态
?mode=codex               Codex 形态（预览默认）
?visual=whale             鲸鱼娘主题
?visual=liang             梁圣主题
?visual=energy            能量充能
?visual=warp              曲率跃迁
?visual=quantum           量子纠缠
?pvEffort=off             设置预览初始档位（off/minimal/low/medium/high/xhigh/max）
?pvPane=effort            官方预览直接打开推理等级列表
?palette=codex            只影响非角色主题的配色
?effort=off               主会话当前档位
?dark=1                   深色（默认浅色）
?narrow=1                 窄容器（只显示图标）
?provider=openai&model=gpt-5.1-codex   仅影响主会话的 5 档模型
?provider=custom&model=qwen3-32b       仅影响主会话的 3 档模型
```

可组合，例如 `?visual=whale&pvEffort=max`、`?visual=liang&dark=1`。

## 素材说明

`assets/` 里的鲸鱼娘 7 张表情与 `full-body` 来自用户提供的 **Gemini 原创出图**（2048 JPG），本地做了去白底、透明化和 1024 WebP 处理；背景 `whale-bg.webp` 是从这套素材合成的深海场景，不是 Gemini 生成的背景。鲸鱼娘原图的使用需遵守 Gemini/Google 的生成内容条款；旧社区梗图素材已不再引用。

梁系参考帧来自 **liang-intensity-calibrator / 滑动变祖器**，该项目声明图片不随 MIT 共享，仅作预告/原型。这里只用于本地 UI 预览，不随插件安装包分发；正式发布前需要替换为授权素材或取得许可。
