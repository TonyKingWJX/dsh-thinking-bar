# 角色主题素材来源

这些图片只用于本地 UI 预览，不随 DSH 插件安装包分发。

## 鲸鱼娘

- 来源：用户提供的 **Gemini 原创出图**（`鲸鱼娘/off.jpg`、`Minimal.jpg`、`Low.jpg`、`Medium.jpg`、`High.jpg`、`Xhigh.jpg`、`Max.jpg`、`full-body.jpg`，2048×2048 白底 JPG）。
- 本目录 `whale-0..6.webp` 是去白底后的 1024×1024 透明 WebP；`whale-full.webp` 是去白底的全身图；`whale-bg.webp` 是用全身图 + 深海渐变 + 气泡合成的背景（不是 Gemini 生成的背景）。
- 原图使用需遵守 Gemini/Google 生成内容条款；此处不再引用旧社区梗图包。

## 梁圣

- 来源：`liang-intensity-calibrator`（滑动变祖器）的 `public/frames/frame-00..30.webp`。
- 本目录 `liang-bg-0..6.webp` 为 7 个档位完整帧：既做卡片模糊背景，也直接等比缩小成滑块；`liang-hero-0..6.webp` 是模糊/压暗背景版；`liang-thumb-0..6.webp` 是早期裁切备用。
- 该项目声明图片素材不随 MIT 共享；此处按原样收录，仅用于主题演示，署名见仓库根目录 README 的致谢一节。

人物肖像仅作风格参考。
